# UI Preview 工作台改版方案

状态：A 批次主体已实施；纯 React 编辑/预览、DOM 编辑覆盖层和组件注册亦已实施。自由停靠、完整命令/属性剪贴板、命名插槽及 V3 等仍为后续设计。
日期：2026-10-21。
配套文档：[React 游戏 UI 组件接入规范](react-game-ui-component-spec.md)。

## 1. 改版目的

让使用者围绕“找对象、选对象、改布局/属性、验证效果”完成日常工作。
当前实现已改为：对象树常驻左侧，文档/视图设置常驻右侧；预制 React 组件按 `core/ui/prefabs/**/*.ui.tsx` 自动发现，右键“添加 UI”按文件夹生成树状菜单，移除独立组件库面板。下文旧的组件库/设置弹窗布局为设计过程记录，以本段及 Lab README 为准。
真实 React 编辑能力按组件规范建设，面板整理可先独立实施。

## 2. 三个项目参考的取舍

以下现状来自仓库代码和各 Lab 的维护文档，不代表 UI Lab 已实现这些能力。

| 来源 | 已有优点 | UI 编辑器采用方式 |
| --- | --- | --- |
| Scene Environment | 公共 ObjectHierarchy、InspectorSection，分组折叠、摘要、面板停靠与布局记忆 | 统一对象行样式、属性折叠和面板操作 |
| Dungeon Map | 工作台外壳、两侧调宽/收起、设置窗口、底部诊断、窄屏覆盖面板 | 作为外壳结构参考，将全局设置与对象属性分离 |
| Dungeon Map | 不同浏览索引有独立搜索，点击组件可定位对应属性 | 层级、组件库、问题列表各自独立搜索；选择与属性定位联动 |
| Dialogue Map | 点击具体内容会展开、高亮相关属性组，保留其他组的折叠状态 | 增加可带属性定位目标的选中动作 |
| Dialogue Map | 节点剪贴板与属性剪贴板分开，分组粘贴有兼容检查 | 分别提供复制节点、复制外观、复制布局等明确操作 |
| Dialogue Map | 鼠标中心缩放、聚焦选区、空格平移、右键菜单、混合值批量编辑 | 统一 UI 工作区的操作反馈与批量编辑入口 |

不移植地图的空间挂载索引、对话图的端口连线和编译模型。
对话图会将当前属性组置顶；UI 编辑器默认采用“展开、滚动定位、短暂高亮”，
保持各组顺序稳定。将来如有需要，再提供显式的固定常用组功能。

## 3. 默认工作区

| 位置 | 默认显示 | 按需打开 |
| --- | --- | --- |
| 顶部文档栏 | 文档名称/切换、修改状态、撤销/重做、编辑/预览、保存 | 文档管理、导入导出、工作区设置、帮助 |
| 左侧 | 对象层级 | 组件库、资源浏览 |
| 中央 | UI 画面与编辑覆盖层 | 选区操作条、右键菜单 |
| 右侧 | 当前选择的属性 | 未选择时显示文档概况；多选时显示批量编辑 |
| 底部 | 选择数量、缩放、画布尺寸、问题数量、简短操作反馈 | 可展开的问题列表 |

默认左栏约 280px、右栏约 340px，最终值根据实际视窗验证；保留中央工作区。
侧栏可以调宽、收起和恢复。组件库与对象树默认切换显示，避免再次抢占树的高度。
需要同时浏览时允许通过已有 DockWorkspace 机制上下或左右停靠；首次打开不强制展示多面板。

只提供“编辑/预览”主切换，两者均使用真实 React 组件。没有 Canvas 模式、回退或渲染器选择。

## 4. 对象层级

对象行固定为：展开箭头、类型图标、名称、简短状态、显示/锁定快捷操作。
名称占主要空间；类型、ID 和布局细节放在次级信息或悬停信息中，避免每行重复堆字。

- 搜索名称、组件类型和 ID，保留匹配节点的祖先路径；清空搜索恢复原展开状态。
- 提供定位所选、展开全部、折叠全部；画面选择同步定位树条目。
- 明确区分自身隐藏/锁定与父级继承的隐藏/锁定。
- 合法投放有父级/插槽提示，非法投放说明原因。
- 后续命名插槽按组件规范作为投放区域显示，不伪装成普通实例。

预设新建表单、长说明、整备演示状态不放在对象树下面常驻。
组件库显示分类、搜索、图标和简短描述，插入前显示目标父级/插槽。

## 5. 属性面板

顶部固定摘要：节点名称、组件显示名、父级路径、可见/锁定状态。
ID、definitionVersion 等开发信息进入默认折叠的高级信息。

| 分组 | 默认状态 | 折叠摘要举例 |
| --- | --- | --- |
| 布局 | 展开 | 右下锚定 · 160 × 44 |
| 内容 | 展开；无字段则不显示 | 打开装备 |
| 外观 | 折叠 | 20px · 深色背景 |
| 数据绑定 | 折叠 | 2 项绑定 · 1 项异常 |
| 事件 | 折叠 | 按下 → 打开装备 |
| 高级信息 | 折叠 | game.button · v1 |

布局先展示常用相对位置、尺寸、锚点预设和父级关系。
自定义锚点范围、Pivot、尺寸 Δ 等放进布局内的高级项；拉伸轴显示对应边距。
用“相对父级”“相对画布”等标签直接解释字段含义。

沿用对话图的选中联动：选择动作可以携带 group/path，例如从绑定警示定位到
“HP → 当前值 → 数据绑定”；自动展开目标祖先组、滚动并高亮。
只选中一个按钮不等于已选中按钮内部文本，不能自动推断并跳转私有 DOM 属性。
点击文字独立节点或明确的“编辑文字”命令，才定位到内容字段。

分组提供复制/粘贴属性和恢复默认入口。粘贴只写该分组允许的字段，
不改节点身份、父子关系和引用；布局粘贴默认复制局部布局，因此换父级时可能改变画面位置，
执行前明确说明语义。不兼容的组件禁用粘贴并显示原因。

## 6. 多选、画布与命令

多选时面板明确显示选中数量、共同属性、对齐和分布，不继续假装只编辑最后一个节点。
混合值显示“多个值”，只修改用户操作的字段；锁定项排除并说明数量。

画布采用对话图已有的导航习惯：鼠标中心缩放、空格＋拖动/中键平移、F 聚焦选区、
适应画布、框选、Esc 取消操作。输入框保留文字编辑快捷键，菜单和弹窗不触发画布命令。
若跨 Lab 存在快捷键差异，应在实现前统一映射并在帮助中列明，不直接复制冲突规则。

右键菜单按上下文提供复制、粘贴、副本、删除、聚焦、成组/解组和父级操作。
空白区域可在当前位置插入已注册组件；节点和属性剪贴板独立。
节点复制按组件规范处理整棵子树及声明的节点引用。

整个编辑面板内所有入口调用同一套命令：工具栏、菜单和快捷键不能各自实现一套复制/删除。
拖动预览到松手提交一次历史，Esc 还原；批量修改和分组粘贴也各为一次历史。

## 7. 设置和问题面板

文档设置：名称、Key、画布逻辑尺寸、安全区、预设管理。
视图设置：网格、吸附、辅助线、缩放显示、过渡期渲染方式。
工作区设置：面板显隐、停靠、宽度、密度、恢复默认布局。

文档设置影响保存及编辑历史；视图/工作区偏好不修改 UI 文档。
工作区状态使用 UI Lab 自己的版本化存储键，不读取或覆盖其他 Lab 的偏好。

底部问题数可展开问题列表，按严重程度、节点和属性展示。
点击问题同时选中节点、定位画面/层级树、展开相关属性；不提供只会跳到 ID 文本的空联动。
没有待实现的绑定/事件验证能力时不展示“校验通过”，只展示实际已执行检查的范围。

## 8. 实现组织

优先复用 `core/ui/editor-kit` 已有的 DockWorkspace、dockLayout、ObjectHierarchy、
InspectorPanel 和 InspectorSection。需要属性组定位、折叠记忆、通用命令菜单等能力时，
以可选接口扩展公共组件；不要把三个 Lab 的领域实现整段复制进 UI Lab。

参考 `DungeonMapWorkbench.tsx` 的外壳分工，将 UI Lab 拆为工作台外壳、
层级/组件浏览、属性面板、工作区偏好、编辑命令及画面宿主。
共享 UI 文档和 React 组件协议留在 Core，整备演示及示例数据留在 Lab。
这些是后续实现建议，本文件不改变现有目录归属或运行入口。

## 9. 实施批次与验收

**A：信息组织和面板秩序。** 移出低频表单、默认保留对象树、统一对象行，
加入属性折叠/摘要、侧栏宽度及显隐记忆、设置窗口与底部反馈。

**B：操作联动。** 属性定位、上下文菜单、快捷键、分组属性剪贴板、
批量编辑、聚焦与鼠标中心缩放。统一命令与历史记录。

**C：真实 React 编辑。** 按组件接入规范统一注册表、DOM 编辑覆盖层、
命名插槽、绑定与事件设置、V3 迁移及正式游戏宿主验证。

每批次验收时都检查：

- 1366×768 和 1920×1080 下对象树可连续浏览，工具栏不被挤出。
- 侧栏收起后能恢复，窄视窗采用覆盖面板并能关闭返回画面。
- 刷新恢复宽度、显隐及折叠状态；恢复布局不修改 UI 文档。
- 定位属性会展开并高亮正确字段，其他分组顺序与折叠状态保持稳定。
- 搜索、重排、预设切换和多选不导致选择/属性对象错位。
- 字段编辑、拖动、粘贴和撤销重做保持一致；浏览与工作区操作不产生未保存误报。
- 兼容预设的保存链路保持完整，界面验证不写入正式预设。
