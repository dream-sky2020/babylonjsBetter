# 玩家空间交互组件

日期：2026-10-18。

在地图数据编辑器 Lab 选择空间物体、障碍或 Agent 的 Entity，在检查器“新增 Component”选择“空间交互”并添加。“玩家推动响应”支持阻挡 / 推动 / 换位，缺省或禁用等于阻挡。组件为可选单实例，支持批量字段编辑。

先将空间物体的运动能力设为可移动；推动还需开启允许推动，换位不要求允许普通推动。非法枚举、重复交互组件、缺少 Body、固定物体响应推动/换位等由定义编译报告。空间不足、目标忙碌、存在额外墙体时仍会受阻，不自动改用另一种动作。当前沿用动作内核的四方向单箱推动、相邻非环绕换位范围。

组件通过现有 glob 注册，无编辑器私有字段。配置经过 Store、历史、Delta 和 v3 往返；编译后的响应位于共享 Body 中。玩家普通及相对移动在既有受阻接管之后读取目标配置，提交已有 requestPush/requestSwap。忙碌状态、连续玩家姿态、同步格步、观察通知和长按续步接入原链路；Agent AI 未添加新的行为决策。
