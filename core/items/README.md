# Items Core

装备与技能均是物品定义，角色装备位置引用物品单元。`types.ts` 定义通用物品、装备属性修正、装备技能和使用损耗规则；`inventory.ts` 管理普通堆叠与独立实例的取放、附魔；`skills.ts` 合并角色学习等级、装备授予等级和等级加成；`wear.ts` 处理一次使用后的损耗。

普通且无耐久的装备按定义 ID 堆叠。附魔时从堆叠取一件，生成有实例 ID 的独立物品；清除全部独有状态后可重新合堆。有耐久的物品从创建时就是独立实例。

`breakChance` 是每次符合条件的使用结束后触发损耗的概率。无耐久物品触发时损坏一件；有耐久物品触发时扣除 `durabilityLoss`，耐久归零才损坏。未触发时不扣耐久。

`usage.ts` 定义可使用物品的库存和效果规则。每个物品的 `storage` 分别限制战斗背包和仓库的数量；`use.battle` 与 `use.field` 可各自定义目标、消耗方式和效果，也可引用相同的 `effectSetId` 共用效果。效果是数据列表，目前支持生命／魔法／技能值恢复、伤害、状态和事件 ID。事件由调用方交给游戏系统处理。

战斗使用从背包取物品，战斗外使用从仓库取物品。`transferItem` 用于非战斗转移；`restockItem` 从仓库把所选物品补到背包上限，实际补入时返回 `turnCost: 1`。`resolveItemUse` 接受调用方已经选好的目标，返回库存、目标状态、事件和回合消耗；它是纯数据结算函数，不直接推进战斗时钟。使用后的 `wearCheck` 沿用上述损耗语义。具体战斗系统应在自己的行动提交阶段应用结果并消费返回的回合数。

技能的 `modifiers` 是装备或启用期间的被动属性；`active.battle` 和 `active.field` 为可选主动配置，两者可与被动同时存在。主动配置共享物品的目标与效果（支持效果组），独立定义 `cost: { mp?, sp? }` 和 `turnCost?: 0 | 1`。战斗默认1回合，战斗外固定0回合。`resolveSkillUse` 要求调用方根据角色装备/启用状态提供 enabled，并传入已按阵营选定的目标；返回扣费后的 caster、效果后的 targets 和 events，所有输入保持不变，不扣库存。被动属性由调用方在装备/启用时汇总，不能从仓库持有状态自动生效。
