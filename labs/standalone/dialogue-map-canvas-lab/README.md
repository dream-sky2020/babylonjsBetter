# Dialogue Map Canvas Lab

编辑器保存 V6。载入 V5 时保留节点、端口与连线，并将旧等待事件的参数转成等值匹配条件。

- 选项节点同时保存对白与选项，每个出口保存一个选项文本；判断节点保存共享内存比较与 all/any 条件。
- 发布事件卡保存事件名、版本、发送参数和可选关联 ID；等待事件卡独立保存字段比较、发布模块、关联 ID、移动开关和超时。
- 执行动作卡复用地图动作数据，支持消息、视觉状态、共享变量与公开服务操作。目标 Lab 下拉框可查看适用的协议；预览可以手动模拟收到事件和超时。
- 判断节点始终有固定的“成立／不成立”两个出口，不提供添加、删除或更改分支的操作。
- 从紫色出口圆点拖到其他节点的灰色入口圆点可创建连线；松开在卡片内容、空白处或自身入口不会建线。每个出口最多一条线，入口允许多条线汇入；从已连接的出口圆点开始拖线会立即删除原连线；未接上新目标或取消拖动也不恢复原线，可通过撤销恢复。
- 保存全部草稿校验出口连线数量和数据形状，允许规则未完成及流程未接完。
- 检查／编译集中报告语义问题，点击诊断定位；未连接出口、不可达节点及无结束出口的流程警告。未接出口编译为结束分支。
- 编译成功可导出独立 instructions JSON；修改草稿或切换检查入口后需要重新编译。
- 保留撤销重做、文字换行省略及鼠标中心缩放。编辑器不执行事件、不分配 Lab 共享内存。

验证入口：npm run test:dialogue-map、npm run typecheck:dialogue-map、python -m unittest discover -s python -p test_dialogue_map_v5.py -v。

对话和选项统一为 choice 节点，同时支持对白与选项。默认一个“继续”选项，增加选项即可分支。

每张卡片固定一个输入端口，面板不提供添加或删除输入操作；多个出口仍可汇入同一输入。客户端与保存接口拒绝零输入或多输入卡片。

判断卡片统一使用公式，例如 `{石障计数} >= 3`。变量复用预设中的文本变量绑定，画布直接显示公式。预览填入模拟值后可按计算结果进入成立或不成立出口。

属性面板始终展示所属卡片的完整编辑区。选中对白、选项、输入、判断方式或某条条件时，对应编辑区自动展开、高亮并置顶，面板返回顶部；其他编辑区保留折叠状态，展示排序不改写数据顺序。判断方式和比较行支持画布独立选中。

对白与选项各自使用集合大面板，条目编辑区作为内部小面板。添加、选中条目和删除操作集中在所属集合，删除选项同步删除关联连线。选中条目时展开并置顶父面板与对应小面板，输入端口独立保留。

旧判断卡载入后会转换成公式，保留原来的成立／不成立出口和连线。

事件节点使用 events 列表与事件集合面板，等待模式固定一个事件，触发模式允许多个事件并按列表顺序编译，至少保留一个。画布逐条展示事件，选中事件展开并置顶父子面板。多事件切换等待前需手动删到一个。唯一示例同步更新为列表，保存接口校验数量。

流程预览由“预览选中节点”启动，以当前草稿快照运行，选择对白／选项／条件／事件内容时从所属节点开始。DialogueFlowPreview 提供弹窗对白、逐句继续、选项、手动判断通过／不通过、结束与重启、叉号与 Esc 退出。事件仅记录模拟触发，等待自动放行，不读取共享内存或分派真实事件。连续事件最多自动执行 100 步，循环与悬空目标停止并提示。

节点通过 `display.whitespace` 分别保存标题（`header`）、内容行（`content`）、出口行（`outputs`）、内容顶部（`top`）和设定高度产生的额外留白（`height`）。各项默认为 `true`。旧预设里的 `sections` 和 `bottom` 在读取时忽略。关闭 `height` 后按内容最小高度显示，原先设定的 `heightUnits` 仍保留。

顶部全局留白按钮已移除。每个节点的“留白设置”面板提供 7 个复选框和“全部保留／全部收紧”。可以只保留标题、收紧其他区域。点击卡片留白区域、面板标题或节点属性中的“选择留白设置”按钮会选中、高亮、展开并置顶面板，属性滚动回到顶部；画布同时高亮留白区域。修改参与草稿保存、撤销和重做；连线端点、点击区域和适配视图均按节点各自的布局计算。

画布工具栏的“操作说明”提供当前画布操作、接线、留白、检查入口、预览及保存说明，支持关闭按钮、点击遮罩或 Esc 退出并恢复焦点。工具栏顺序为“预览选中节点”“操作说明”“撤销”“重做”。


## 图编辑操作（2026-10-15）

- 节点多选与属性选中独立维护：编辑选区内某个节点的内容不会清空选区。左侧条目普通点击单选；Ctrl（或 ⌘）点击追加选择，Alt 点击减选，Shift 点击反选，画布和左侧条目使用相同规则。
- 空白处左键拖动框选，与框相交即命中；普通框选替换选区，Ctrl（或 ⌘）框选仅追加未选节点，Alt 框选仅取消命中的已选节点，Shift 框选反选命中节点。方式在按下鼠标时确定，拖动中松开修饰键不改变操作；同时按多个键时优先级为 Alt、Ctrl／⌘、Shift。框上显示当前方式及选中数量，Esc 恢复框选前的选区。中键或空格＋左键拖动平移，滚轮保持鼠标锚点。Esc 取消手势，点击空白处或无手势时 Esc 清空选择。
- 拖动选中卡片的标题或留白区域移动整组选区，吸附整体位移并保留相对位置。移动预览不写草稿，松手只提交一条撤销；Esc、丢失指针捕获或窗口失焦取消未提交的移动。
- 复用 core/ui/menu 的通用右键菜单。右键选中节点保留多选，右键未选节点切换选择；提供复制、剪切、错开一格的副本、删除、聚焦、对齐／分布、设为检查入口和流程预览。右键本身不更改检查入口。空白菜单在点击世界坐标新建节点或粘贴。
- Ctrl+C/X/V 操作节点剪贴板，Ctrl+D 生成副本，Ctrl+A 全选，Delete 删除选区及关联连线，F 聚焦选区。输入控件保留原生文字操作，菜单、弹窗和活动拖动不会触发图编辑快捷键。
- 节点剪贴板为独立深拷贝快照，支持同页面跨预设粘贴；仅携带选区内部连线。粘贴重建节点、对白、端口与连线 ID，保留相对位置及固定判断出口。右键粘贴以点击位置为落点，快捷键在画布中心粘贴并逐次错开；粘贴全部构建并校验成功后一次提交。剪切先建立快照，再删除；撤销不会清空剪贴板。允许删除最后一个节点，空图右键可重建。
- 每个可编辑 Inspector 面板提供独立属性复制粘贴，属性剪贴板不会覆盖节点剪贴板。节点属性仅复制标题／标签；外观复制 display；留白只复制七项设置；对白、条件、事件支持单条与集合；端口只复制标签。诊断和固定判断出口只读。
- 选项集合替换要求数量一致，只更新现有标签，保留端口和连线；“追加为新选项”生成新端口。对白、条件、事件集合的替换与追加使用不同按钮。等待节点禁止追加事件，不兼容操作禁用并显示原因。
- 多选摘要通过“批量编辑属性”显式开启批量颜色、尺寸和留白设置，混合值显示“混合”，仅写入用户修改的字段。至少 2 个节点支持边缘对齐，至少 3 个支持等间距分布，使用实际内容布局尺寸；每次批量操作一条撤销记录。
- 两个剪贴板及选区仅属于当前页面，不写入预设，刷新后清空。页面内操作说明同步覆盖新菜单、快捷键、框选、事务与属性粘贴规则。
