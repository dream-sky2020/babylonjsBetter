# Puck 界面编辑器使用说明

## 打开编辑器

项目已安装开源的 `@puckeditor/core` 0.23.0，无需注册 Puck Cloud 或填写 API Key。

在项目目录运行 `npm run dev`，默认入口：

- 编辑界面：[Puck 编辑器](http://localhost:1184/labs/standalone/clash-lab/editor.html)
- 运行界面：[Clash 战斗试验台](http://localhost:1184/labs/standalone/clash-lab/index.html)

也可以从项目首页“普通 Lab → Puck · Clash 界面编辑器”进入。已经运行开发服务时直接打开链接即可。更换依赖后若页面空白，请重启开发服务。

## 第一次使用

1. 左侧选择组件，拖到中间画布。默认示例已经放好左右阵营、操作按钮和日志。
2. 点击画布中的组件，在右侧编辑属性。选中“单位状态卡”，可以将“绑定阵营”改为右侧。
3. 拖入“网格布局”，设置列数和间距；把组件拖入网格内部。拖入“分组卡片”可以将相关控件放在同一卡片内。
4. 选中“战斗动作按钮”，修改按钮文字，并选择“开启拼点”“回合结束”或“清空日志”。
5. 点击上方“交互预览”，即可修改生命值、护盾和出战技能，实际执行战斗。点击“返回编辑”继续调整布局，战斗状态会保留在当前页面中。
6. 点击“保存布局”。显示保存成功后，点击“打开运行页”，即可使用保存的界面。

设计模式下，画布内的战斗按钮和表单不可操作，便于选择和拖拽组件；需要运行战斗时切换到“交互预览”。编辑器工具栏支持撤销、重做；选中组件后可以复制和删除。

业务控件中的单位、技能使用标签页切换：点击“＋ 新建”创建并立即选中，点击“删除”删除当前项。切换标签保留当前页面中的修改，重命名同步更新标签；删除当前项后自动切到相邻项。标签过多可横向滚动，也可在标签上使用左右方向键和 Home/End。

## 已接入的组件

| 组件 | 可配置项或功能 |
| --- | --- |
| 标题与说明 | 标题、说明文字 |
| 网格布局 | 1–4 列、间距、嵌套组件；窄屏自动单列 |
| 分组卡片 | 卡片标题、嵌套组件 |
| 单位状态卡 | 绑定左/右选中单位，实时显示生命值、护盾、速度和状态 |
| 单位与技能控制 | 选择出战单位、技能，调整 HP 和护盾 |
| 技能详细编辑器 | 绑定左/右选中单位的出战技能，编辑骰子和技能效果 |
| 战斗动作按钮 | 设置文字和点击动作 |
| 战斗日志 | 显示当前战斗日志，可调整高度 |

绑定阵营后，组件始终跟随该阵营当前选中的单位。血量与护盾直接订阅现有战斗状态，不需要手动刷新。需要原有的完整单位、状态、技能管理时，可打开运行页的“完整战斗参数”。该页面仍保留原来的编辑器。

## 保存、备份与恢复

- **保存布局**：保存到当前浏览器当前站点的本地存储；不会发布网站、上传云端或改写项目源码。编辑器内两个“保存布局”按钮作用相同。
- **导出 JSON**：下载当前布局，包括尚未保存的修改，方便备份、提交 Git 或分享。
- **导入 JSON**：载入导出的布局；需要再点击“保存布局”才会替换运行页的布局。无法识别的组件和损坏的数据会被拒绝，原布局保持不变。
- **默认布局**：将编辑器恢复到初始示例；点击“保存布局”后才会替换已有保存内容。

布局只包含组件、属性和嵌套关系，不包含单位 HP、技能修改或战斗日志。刷新页面、跳转到另一页面时，战斗状态仍恢复为示例数据。切换浏览器、端口或主机名（例如 localhost 与 127.0.0.1）时本地存储互不共享，可以用 JSON 导出/导入转移布局。

当前布局使用稳定键 `clash-lab.puck-layout.v1`。若本地数据损坏，运行页会提示错误并显示默认布局，不会自动覆盖原数据。

## 给开发者：新增可拖拽组件

1. 在 `puck/layoutData.ts` 的 `ClashBlocks` 中定义可保存的属性。
2. 在 `puck/clashPuckConfig.tsx` 的 `components` 中注册组件、中文名称、属性字段、默认值和 React 渲染函数，并加入合适的分类。
3. 在 `parseLayout` 中加入该组件的属性校验；布局保存为 JSON，函数和 React 元素不能写进布局。
4. 业务组件通过 `useCombatStore` 订阅数据，通过已有战斗 API 执行动作。使用 `puck.isEditing` 区分设计与运行模式。
5. 需要默认显示时，更新 `createDefaultLayout()`。不要直接修改用户已保存的布局。

组件只在代码中注册一次，后续就可以通过拖拽重复使用。Puck 不会自动从任意 React 页面生成组件，也不会自动生成新的战斗规则。

验证：`npm run typecheck:clash`、`npm run test:clash`、`npm run test:lab-entries`。

官方参考：[入门](https://puckeditor.com/docs/getting-started)、[组件配置](https://puckeditor.com/docs/integrating-puck/component-configuration)、[嵌套与多列布局](https://puckeditor.com/docs/integrating-puck/multi-column-layouts)。
