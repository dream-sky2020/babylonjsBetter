# Press Turn · 大小行动点战斗 Lab

独立于 Clash Lab 的行动点制战斗原型。沿用紧凑 XP 工控台外观，拥有自己的类型、示例、Zustand store、纯函数结算引擎及布局存储，不导入 Clash 战斗代码。

## 三个入口

- `index.html`：Puck 运行页，读取本 Lab 已保存的 Puck 布局。
- `editor.html`：Puck 编辑器，可拖入绑定我方或敌方的角色数据编辑器、操控面板、行动点、指令、重开控制、日志、规则、JSON、多列和 XP 窗口组件；设计模式禁用业务操作，“交互预览”允许执行战斗。
- `grid.html`：React Grid Layout 工作台，面板可拖动、缩放、显隐、锁定，使用页面全部宽度；小于 900px 单列展示，不覆盖桌面布局。

项目首页可拖拽 Lab 分组提供三个入口。运行 `npm run dev` 后访问 `http://localhost:1184/labs/draggable/press-turn-lab/grid.html`。

## 操作

1. “我方角色数据”和“敌方角色数据”分别编辑对应队伍，单位与技能用标签切换。名称、HP/MP、攻击/防御、技能威力/属性/命中/暴击/MP 消耗/范围、八类属性相性均可编辑。新建和删除只操作所属队伍；编辑对象选择不改变当前行动者和战斗目标。
2. “战场总览”独立展示回合/阶段、行动点和双方全员状态；“操控面板”展示当前行动者，并在行动列表下方展开技能、目标、换手队友或整备选项。所有行动统一点击“确认行动”，不弹窗；取消不扣点。单体目标显示基础信息，治疗只选择己方存活目标。
3. “行动指令”保留掷判模式、结束阶段和行动者调试切换。伤害、治疗、阶段和扣点详情在独立的“结算日志”中显示。每个角色始终可以普通攻击、防御、换手、空过；普通攻击为零 MP 物理单体，即使删除对应技能也可用。
4. 普通执行按命中率/暴击率随机；必定命中不暴击、强制暴击、强制未命中用于复现规则。示例先锋火炎命中冰霜守卫：220 → 156 HP，3大/0半 → 2大/1半，轮到术士。
5. 防御减半承伤，到本方下一阶段开始时解除。换手与空过都采用半点规则（大点变半点；没有大点时消耗一个半点）；换手交给指定存活队友，空过按队伍顺序轮转。耗尽行动点自动切换阶段；也可主动结束阶段。双方均可手动或点击“自动选择并执行一次行动”，每次点击只执行当前行动者的一步，不会持续自动战斗。
6. “按当前配置重开”保留编辑后的队伍/技能/相性，恢复所有 HP/MP，并按当前我方人数开始新战斗。“恢复示例”重新创建初始队伍。新增/删除成员不会中途增减本阶段点数；重开或换手时重新计算。

## 整备、逃跑、对话与观察

工具栏“整备面板”打开独立 JRPG 风格配置窗口，可选择我方/敌方及角色，编辑武器、防具和八个技能装备槽。先选择槽位，再点击仓库技能装配；替换会将原技能放回仓库，可单独卸下，支持主动/被动筛选及攻防预览。“保存整备配置”才应用草稿，“撤销未保存修改”恢复当前配置。此窗口用于实验配置编辑，不扣行动点；战斗内“整备”行动仍消耗一次普通行动。

技能库存数量不限，但每名角色最多同时装备八个主动/被动技能，同一技能不重复装配。普通攻击是固定行动、不占槽。被动装备后自动生效，不出现在主动行动列表；示例“力量心得”“坚守心得”分别提供攻击/防御 +4，默认放在仓库。可在角色数据面板新建或编辑技能，类型可选主动伤害、主动治疗、被动加成。

- 整备：从示例武器（制式武器、重刃、轻刃）和防具（常服、皮甲、重甲）中选择，使用同样的八槽界面装配角色已有技能。确认后才应用更换并消耗一次普通行动，取消不生效。装备按差额更新攻防，被动动态计算，重复整备不叠加加成；未装配技能不会出现在可执行技能中，自动策略也不使用。普通攻击始终可用。重开保留装备与装配，恢复示例恢复默认配置。
- 逃跑：基础版必定成功，确认后撤离并结束战斗，手动、自动行动和换阶段均停止；重开恢复。
- 对话：选择敌方存活目标并填写内容，消耗一次普通行动，显示固定的警戒回应；当前不改变敌方立场。
- 观察：选择敌方存活目标，消耗一次普通行动，在操控面板和日志中显示真实 HP/MP、攻防、装备、相性与已装配技能。

## Grid 布局微调

窗口四个角均可拖动调整大小，鼠标悬停窗口时显示角标；右上角缩放区域与关闭按钮分开。锁定布局或窄屏单列时禁用缩放。

工具栏“布局设置”展开后可调整触发距离（0–24px）、网格精度（12/24/48 列）、自动补位、碰撞处理及拖动预览（窗口跟随/仅落点框）。默认推荐为 6px、24 列、关闭补位和自动让位。自动补位只控制向上填空，碰撞处理独立控制拖入占用区域时让位或阻止重叠。旧设置自动补上“自动让位”。精度切换不改变现有窗口尺寸和位置，只改变后续拖动/缩放步长。

点击“战场置顶”可将战场总览铺满工作区顶部，将冲突窗口下移并保存布局；锁定或窄屏时禁用此操作。

“碰撞处理 → 自由叠放”允许窗口相互覆盖，拖动、缩放和位置输入均不让其他窗口移动，并自动关闭向上补位；点击窗口或聚焦内部控件会置顶。仍保留网格吸附与工作区边界。模式和重叠位置自动保存，置顶顺序仅在当前会话保留。

选择任意窗口后，填写横向/纵向位置及宽高并点击“应用位置与尺寸”，支持 0.25 标准格。越界或非自由叠放模式下重叠时显示提示并保留原布局；隐藏窗口、锁定布局和窄屏单列下禁用微调。设置跟随布局自动保存、导入导出；“恢复推荐设置”只重置手感，“恢复默认布局”同时重置几何和手感。

## 自动一步

`autoAction.ts` 以当前阶段和行动者选择一个行动，自动选技能和目标后调用同一结算引擎，沿用“掷判模式”。仅考虑 MP 足够的技能与存活目标，避免无效/反射/吸收；全体攻击有任一无效类目标时跳过。评分考虑有效伤害、弱点、击杀和治疗收益，对低于半血队友的治疗增加优先权。没有安全可用技能时让过。日志记录选择理由。选择策略不改伤害和行动点规则，不启动计时器或自动循环。

## 已确认的首版规则

本实现以用户确认的规则为准，作为《暗喻幻想》/《女神转生》风格的可测试原型，不宣称完整复刻任何一作。

| 行动结果 | 行动点 |
| --- | --- |
| 普通命中、耐性、治疗、防御、整备、对话、观察 | 优先移除一个半点，否则移除一个大点 |
| 弱点、暴击、换手、空过 | 一个大点变为半点；没有大点时移除一个半点 |
| 未命中 | 移除两个图标，半点优先；不足两个则耗尽 |
| 无效、反射、吸收 | 清空本方剩余图标 |

弱点与暴击同时出现只奖励一次。全体攻击对每个目标分别计算伤害，整次行动只结算一次图标，优先级为无效类 > 未命中 > 弱点/暴击 > 普通。换手时按下一方存活成员数补充大点，从首名存活者开始按队伍顺序轮流行动。敌方阶段结束后回合数加一。全灭立即结束，不补充下一方点数。

基础伤害 `max(1, 威力 + 攻击 - 防御)`；弱点和暴击分别 ×1.5，耐性和防御姿态分别 ×0.5，结果向下取整且至少为1。万能忽略相性。反射对行动者造成一次伤害，不递归反射；吸收恢复目标 HP，上限为 maxHp。技能支付一次 MP，未命中/无效仍支付；MP不足、无效行动者或目标被拒绝，不扣资源。治疗不复活、不触发弱点/暴击。

首版尚未加入 Archetype、合题/协同技能、召唤、Buff/Debuff、异常状态或持续自动战斗。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `types.ts` | Unit / Skill / Battle / Icons / Action，属性与相性枚举 |
| `data.ts` | 初始 3 对 3 队伍，新建单位/技能默认值 |
| `engine.ts` | 行动点消耗、伤害/治疗/相性、顺序、换手、胜负、重开；不依赖 UI 或 store |
| `store.ts` | 会话状态及编辑动作，调用纯函数引擎 |
| `playerContext.ts` | 统一推导当前行动者、技能、有效目标及战斗结束状态 |
| `autoAction.ts` | 双方通用的单步行动选择与理由，独立于伤害结算 |
| `widgets.tsx` | 两方角色编辑、操控面板与基础卡片、行动点、指令调试、独立日志和规则组件 |
| `layouts.ts` | Grid/Puck 默认布局、导入校验、独立存储键 |
| `GridWorkspace.tsx` | Grid 拖动、缩放、显隐、锁定、导入导出 |
| `puckConfig.tsx` / `PuckWorkspace.tsx` | Puck 组件注册、运行与编辑页 |
| `style.css` | 本 Lab 独立的 XP 工控台样式 |

布局键保持不变，两种 JSON 不可互换。Grid 当前格式 press-turn-grid-v7，共九个面板。v1–v6 保留或补齐独立总览和操控窗口，v5 合并布局自动拆回两个窗口；在已有窗口下方补可见整备面板，保留原几何、设置、锁定与显隐。Puck 同步补整备面板与独立总览。

仅布局保存在当前浏览器；战斗数据、编辑内容、日志、目标和掷判模式不持久化，刷新或切换入口恢复示例。目标和掷判模式在当前页面 store 中共享，因此多个玩家操控组件也保持一致。每个页面的战斗会话独立。

检查：`npm run typecheck:press-turn`、`npm run test:press-turn`、`npm run test:lab-entries`。


公共工作台与配置约定见 [可拖拽工作台说明](../../kit/draggable/README.md)。旧 standalone 地址仅保留跳转，原布局存储键保持不变。
