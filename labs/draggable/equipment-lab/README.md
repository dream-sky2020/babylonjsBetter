# 整备 Lab

人物面板现在收录成长、资源、基础战斗、行动与伤害、异常与失衡、生存与守护、隐身及条件加成属性；成长组包括等级上限、经验值倍率和未分配升级点。每项带通用名称、单位和含义；点击属性会在信息面板显示说明与当前值，重新选择物品会恢复物品信息。Grid 人物面板的“显示版本”可在数值为主的“属性版”和名称、说明为主的“解释版”之间切换，此选项随 Grid 布局保存。示例角色为新增属性提供初始数值；现阶段装备仍只加成原有的攻击、防御、魔力和敏捷，其余属性供整备展示，尚未接入战斗结算。

属性定义与五阶段装备修正计算由 `core/combat/` 提供；物品堆叠、独立实例、附魔、装备技能和使用后损耗由 `core/items/` 提供。本 Lab 保留样例角色初始值、物品目录和显示格式。装备技能使用稳定 ID 计算，界面用样例的中文技能名和直接描述展示。装备信息面板展示损耗概率、耐久、附魔与技能等级；按钮可对当前装备附魔、清除附魔和模拟使用一次。

仓库、装备、技能面板支持独立的1–4列排列。Grid 中右键窗口标题/标签，可直接选择列数，也可选中面板后在布局设置中调节；设置随布局保存、导入导出并可撤销/重做，合并标签组内各面板独立。Puck 编辑器选中对应 Panel 组件后可调整“内容列数”。

每个人物持有独立的 `skillStock` 技能仓库。切换人物后显示其技能数量，装卸、替换、丢弃、最强装备及全部卸下仅操作该人物技能库存；武器、防具等普通装备继续使用全队共享 `stock`。技能目录共用定义，但持有数量不共享。仓库标题显示当前技能所属人物。

仓库单击查看信息、双击立即装备、右键卸下当前人物的该物品并返还仓库；装备/技能位置也支持右键卸下。仓库为零的物品仍可查看和右键返还。物理装备自动定位对应部位；技能优先选中技能位，否则使用第一个空位，满八槽时提示先选择替换位置。Puck 设计模式禁用业务操作。

三个入口：`index.html` 运行保存的 Puck 布局，`editor.html` 编辑 Puck 布局，`grid.html` 独立 Grid 工作台。首页可拖拽 Lab 分组可进入。

六个可装配面板：仓库、按钮列表、人物、信息、装备、技能。直接共用 Press Turn 的紧凑 XP 窗口、工具栏、按钮和表单样式；选择人物与部位、从仓库选物品、确认装备。技能与武器、盾牌、头部、身体、饰品使用同一个物品目录和装卸函数，技能使用人物独立仓库，普通装备使用全队共享仓库，主动与被动合计八槽，同一人物不重复装配相同技能。技能面板展示全部八个位置，仓库可切换查看全部技能（含未装备技能）。被动属性立即计入人物与替换预览。默认头像为文字占位，无外部素材。

最强装备按物品属性修正值总和稳定排序，不评估战斗策略；可卸下当前、全部卸下（包含技能）、丢弃仓库选中物品一份。普通无耐久装备可堆叠；附魔或有耐久的装备独立列出。`breakChance` 在使用后才判定：无耐久物品触发时损坏，有耐久物品触发时扣耐久，到零才损坏。示例数据每页独立、刷新重置，不消耗战斗回合，与 Press Turn 的战斗状态无耦合。

Grid 支持自由叠放、无自动补位、点击置顶、四角缩放、锁定、隐藏、24/48/96列吸附、拖动阈值和坐标尺寸输入；窄屏单列不覆盖宽屏布局。Grid 与 Puck 使用独立本地键 `equipment-lab.grid.v1` 和 `equipment-lab.puck.v1`，可分别导入导出 JSON。Puck 中可选面板内容、标题、高度和多列容器；设计模式禁用装卸操作，交互预览可操作。

代码：`model.ts` 统一装备规则与样例，`store.ts` 共享面板状态，`panels.tsx` 六面板，`layouts.ts` 布局格式校验，`App.tsx` 三入口壳层，`style.css` 整备内容布局；窗口基础样式来自 `labs/kit/draggable/xp-console.css`。

验证：`npm run typecheck:equipment`、`npm run test:equipment`、`npm run test:lab-entries`。


公共工作台与配置约定见 [可拖拽工作台说明](../../kit/draggable/README.md)。旧 standalone 地址仅保留跳转，原布局存储键保持不变。
