# 极限函数计算 Lab

归入 `labs/draggable/`，根据目标极限、起始值和选定模型生成有界趋近函数，观察 X 变化时的 Y、曲线及极限差距。三个入口共用同一套计算面板，已加入首页“可拖拽 Lab”和 Vite 构建。

- `index.html`：运行页。初次打开保留原来的 300px 侧栏、公式、四项结果、曲线和下方双列布局；之后读取 Puck 保存的布局。
- `editor.html`：Puck 编辑器。拖动“计算功能面板”，在属性中选择内容；用“默认侧栏与主区域”“下方双列布局”组织面板。编辑时计算控件禁用，点击“交互预览”可测试。点击“保存布局”后，重新打开运行页生效。“默认布局”恢复初始排列，再保存即可应用。
- `grid.html`：Grid 工作台。拖动标题移动八个窗口，四角缩放；支持隐藏/显示、锁定、标签分组、布局设置和撤销/重做，布局自动保存。

顶部可在 Lab 首页、运行页、Puck 编辑器和 Grid 工作台之间切换。旧 `labs/standalone/limit-function-lab/` 三个地址保留跳转，保留查询参数和锚点。

Puck 与 Grid 布局分别存入本机浏览器 `limit-function-lab.puck.v1`、`limit-function-lab.grid.v1`，彼此独立，可导入/导出 JSON。计算参数只存在当前页会话中，切换页面或刷新恢复默认参数。恢复默认参数不会清除已保存的布局。

## 使用

1. 选择分式饱和、指数趋近、反正切或幂次饱和（Hill）。
2. 输入目标极限 L、起始值 Y₀；填写半程 X（H），即 F(H) = (Y₀ + L)/2。Hill 额外支持幂指数 n。
3. 或勾选“由参考点反推参数”，输入期望曲线经过的 (X, Y)，由所选模型反算 H；参考点 X > 0，Y 必须严格位于 Y₀ 和 L 之间。
4. 拖动曲线上的圆点、在图表区域按住拖动、调节 X 滑块、输入数字或使用 X×2 / X=H / X=0，实时查看 Y。圆点只能沿当前公式的曲线移动，不能独立修改 Y。选择对数 X 轴可观察跨多个数量级的输入；图表范围会包含当前 X。拖动使用指针捕获，移出图表仍可继续，松开或触控取消后停止。
5. “曲线与 X 调节”提供“X 仅允许整数”开关，默认关闭。开启时当前 X 四舍五入；输入、滑块、点击/拖动圆点、快捷按钮都统一吸附为整数，数值输入步长为 1。关闭后恢复小数调节，切换常用示例保留开关状态。H、参考点与图表坐标范围仍是函数参数，不受此开关影响。
6. 下方列出趋近 50%、90%、95%、99%、99.9% 所需的 X，可以直接应用。整数模式使用向上取整的 X，Y 按该整数重新计算，避免向下舍入未达到目标进度。100% 仅在 X→+∞ 的极限意义下成立。
7. 可以复制当前公式、可粘贴使用的 JS 函数，或导出图表范围内最多 201 个 CSV 采样点。整数模式将采样 X 取整、去重后重新计算 Y。计算和导出都在本地进行，不上传、不保存输入，刷新恢复默认值。

示例：极限 L=100、Y₀=0、H=50、分式模型，得到 `F(X)=100X/(X+50)`；X=50 时 Y=50，X=450 时 Y=90，X=4950 时 Y=99。

## 模型与范围

| 模型 | F(X) |
| --- | --- |
| 分式 | Y₀ + (L−Y₀) X/(X+H) |
| 指数 | L − (L−Y₀) 2^(−X/H) |
| 反正切 | Y₀ + (L−Y₀) (2/π) atan(X/H) |
| Hill | Y₀ + (L−Y₀) Xⁿ/(Xⁿ+Hⁿ) |

这些模型在 X≥0、H>0、L≠Y₀ 下单调趋近且不会在有限 X 取到 L；L<Y₀ 时为下降趋近。数学上的极限一般不等于“永远不能取到的值”，本页只针对上述函数族，不是任意表达式的符号求极限器。

数值输入限制：|L|、|Y₀|≤10¹²；10⁻¹²≤H≤10¹²；0≤X≤10¹²；0.1≤n≤8。不支持负 X、超大精度计算或任意表达式执行。生成公式显示的参数会适当舍入，复制的 JS 保留实际双精度参数。

极接近极限时，双精度计算或显示舍入可能让 Y 显示成 L。此时标注“≈”及精度说明，并单独以对数域计算剩余差距；差距小于可表示浮点范围时显示十次幂形式，避免把下溢的 0 当成数学上的已达到。导出 CSV 同时提供差距的自然对数。直接粘贴的 JS 使用双精度，仍有相同舍入限制。

## 代码

- `functions.ts`：模型、稳定数值计算、参考点拟合、进度反算、公式与坐标变换。
- `Chart.tsx`：响应式 SVG 曲线、极限线、当前点、差距线与点击取 X。
- `session.tsx`：共享计算会话与八个面板、参数输入、示例、进度表、复制与 CSV 导出。所有面板读取同一会话；工作台本身不订阅计算变化，避免 Puck 插槽重新挂载时丢失图表拖拽状态。
- `App.tsx`：通过 `labs/kit/draggable/` 公共工作台装配三个入口与 Puck 组件配置。
- `layouts.ts`：默认布局、面板目录、Grid/Puck 保存键与导入校验。
- `style.css`：紧凑 XP 风格计算台与窄屏布局。
- `functions.test.mjs` / `layouts.test.mjs`：公式、拟合、反函数、边界、精度与布局存取回归。

验证：`npm run typecheck:limit-function`、`npm run test:limit-function`、`npm run test:lab-entries`、`npm run build:draggable`。开发服务启动后，运行 `node codex-tools/runElectronVerification.mjs codex-tools/verifyLimitFunctionLab.cjs` 验证真实拖拽、默认布局、Puck 保存和 Grid 刷新恢复。
