# 飞刀与城市风扇贴图缩至 512×512

按用户指定，仅调整以下两个模型引用的全部运行时图片：

| 模型 | 图片 | 调整前 | 调整后 |
|---|---:|---:|---:|
| `artist_realduende/Weapons/ThrowingKnife.glb` | 颜色、法线、ORM 共 3 张 | 4096×4096，11,917,249 字节（11.37 MiB） | 512×512，284,705 字节（278.03 KiB） |
| `artist_rayzngames/CityIndoor/Fan.glb` | 颜色、法线、金属粗糙、自发光共 4 张 | 2048×2048，8,191,757 字节（7.81 MiB） | 512×512，734,681 字节（717.46 KiB） |

颜色/ORM/自发光采用 Lanczos；RGBA 按预乘 alpha 重采样保留透明边缘，ORM 保持线性数据通道。法线采用线性编码域 BOX 平均并重新归一化，8 位编码后的长度误差小于 0.007。PNG 保留 alpha，GLB 只更换 `images[].uri`；通过反向 JSON 对比和 BIN 逐字节比较，验证顶点、索引、UV、网格法线、节点变换、材质参数和采样不变。图片缩小属于用户指定的有损处理。

飞刀原三张图片只被它引用，已从 public/dist 清除。城市原四张图集由 52 件模型共用，因此为风扇生成独立低分辨率版本，保留另外 51 件城市模型的原图；独立 `Fan/TableFan.glb` 和四种配色不变。新增小图加删除旧图后，public 资源净减少 **10,897,863 字节（10.39 MiB）**，不能把风扇共用的大图也算作已删除。Rayzngames 现为 21 张共享图片，107 GLB+图片 54,485,373 字节；七作者现为 112 张图片，126 GLB+图片 13,754,651 字节。

清单、来源/尺寸信息、几何测量及两个作者 README 已同步。`report.json` 保留原始/调整后图片哈希、尺寸、角色、被调整模型与其他资源/原始来源基线。小型旧 GLB 和清单备份位于 `.asset-migration/selected-textures-512/before/`，不备份大型旧图片，D:/Model 来源完全不改动。

`optimizeSelectedModelTextures512.mjs` 首次执行前会验证来源、现有发布哈希和整库引用；`--verify` 对比旧 GLB 和新 GLB 的非图片内容、检查全部 512 PNG、其他资源哈希、来源哈希与旧图无残留。`resize.py` 支持文件工作表和 `--stream <role>` 的二进制管道；`replay.mjs` 接入两套原导入器，重做转换时从原图片数据再次生成相同 512 PNG，避免悄悄恢复大图。城市四图的转换回放已逐字节验证。

`verifySelectedModelTextures512.mjs` 实际 WebGL 加载两件，检查 512 尺寸、PBR/透明镂空、原三角形/边界、实例材质隔离和共享上传，并更新既有测量哈希。飞刀仍 2,376 个三角形，城市风扇仍 6,886 个三角形；七张图各上传一次。两个作者场景及其余六作者总览通过真实加载，七作者仍 112 张图各请求/上传一次，Rayzngames 21 张图各请求/上传一次。两套预设无需修改位置/比例和内容。

默认完整构建、两个变更作者预设的正式 file:// Lab/材质 Inspector、四个其他模型消费者启动均通过。发布校验确认模型/图片/README、预设和索引 public/dist 对应，飞刀旧图无残留。截图和日志位于 `.asset-migration/selected-textures-512/`；完成后清理本轮重建的浏览器缓存和临时小图副本，保留审计与小型备份。

本轮已清理临时图片副本与三处新建的验证浏览器缓存，释放 162,052,155 字节（154.55 MiB）；清理后再次检查两套原导入器/预设、目标图像与几何、来源/其他资源哈希及发布文件。`checkPublication.mjs` 将构建、正式加载、资源对应和清理结果写入 `production-validation.json`。
