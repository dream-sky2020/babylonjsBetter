# Dialogue Map Canvas Lab

V5 数据编辑器，提供选项、判断和事件三类卡片。旧版数据不再读取；village_gate 使用新示例。

- 选项节点同时保存对白与选项，每个出口保存一个选项文本；判断节点保存共享内存比较及 all/any/not 条件。
- 事件节点支持发送或等待模式，保存事件名称、版本及参数值引用。等待模式的参数是匹配条件，可只指定部分参数。
- 判断节点始终有固定的“成立／不成立”两个出口，不提供添加、删除或更改分支的操作。
- 从紫色出口圆点拖到其他节点的灰色入口圆点可创建连线；松开在卡片内容、空白处或自身入口不会建线。每个出口最多一条线，入口允许多条线汇入；从已连接的出口圆点开始拖线会立即删除原连线；未接上新目标或取消拖动也不恢复原线，可通过撤销恢复。
- 保存全部草稿校验出口连线数量和数据形状，允许规则未完成及流程未接完。
- 检查／编译集中报告语义问题，点击诊断定位；未连接出口、不可达节点及无结束出口的流程警告。未接出口编译为结束分支。
- 编译成功可导出独立 instructions JSON；修改草稿或切换检查入口后需要重新编译。
- 保留撤销重做、文字换行省略及鼠标中心缩放。编辑器不执行事件、不分配 Lab 共享内存。

验证入口：npm run test:dialogue-map、npm run typecheck:dialogue-map、python -m unittest discover -s python -p test_dialogue_map_v5.py -v。

对话和选项统一为 choice 节点，同时支持对白与选项。默认一个“继续”选项，增加选项即可分支。

每张卡片固定一个输入端口，面板不提供添加或删除输入操作；多个出口仍可汇入同一输入。客户端与保存接口拒绝零输入或多输入卡片。

判断卡片支持全部满足／任一满足与平铺比较条件，不再支持嵌套条件组和取反。画布逐条显示比较式（共享内存 Key、路径、操作符与常量），复杂组合通过成立／不成立出口连接其他判断卡片。示例使用全部满足的两条条件。

属性面板始终展示所属卡片的完整编辑区。选中对白、选项、输入、判断方式或某条条件时，对应编辑区自动展开、高亮并置顶，面板返回顶部；其他编辑区保留折叠状态，展示排序不改写数据顺序。判断方式和比较行支持画布独立选中。

对白与选项各自使用集合大面板，条目编辑区作为内部小面板。添加、选中条目和删除操作集中在所属集合，删除选项同步删除关联连线。选中条目时展开并置顶父面板与对应小面板，输入端口独立保留。

判断条件也使用集合大面板：满足方式与添加、选择、删除操作集中在父面板，每条比较使用内部小面板。选中比较时父子面板同时展开置顶，条件的存储顺序保持不变。

事件节点使用 events 列表与事件集合面板，等待模式固定一个事件，触发模式允许多个事件并按列表顺序编译，至少保留一个。画布逐条展示事件，选中事件展开并置顶父子面板。多事件切换等待前需手动删到一个。唯一示例同步更新为列表，保存接口校验数量。
