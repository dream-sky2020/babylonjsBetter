# Lab 性能统计工作台

组合式 Lab 自动安装入口：侧栏「Lab 性能统计」→「打开性能工作台」。点击开始采集，在同一场景下执行操作，停止后查看和导出 JSON。搜索和排序不改变采集状态。面板隐藏时继续采集，停止刷新 DOM；显示时每秒刷新一次。

默认按模块汇总：调度任务（包括 enabled 判断）、事件监听和请求处理按注册所有者归属，Host 调度、相机和场景渲染独立列出。切换「模拟与 Debug 任务」可按模块、阶段与任务 ID 查看独立明细；例如 `player-movement` 和 `dungeon-agent` 均分别显示 simulation/update 与 debug/debug-summary。同步嵌套计时扣除已测子调用，保留原返回值、Promise、异常和执行顺序。运行采集默认关闭，不调用时钟；初始化、启动和释放单独记录。

- 同步累计：已覆盖入口的同步自身经过时间，包含其中未插桩的同步子函数，不是操作系统 CPU 时间。
- 每次指标：入口调用分布，含任务启用判断。累计/次数/最大值覆盖本次记录，P95 使用最近最多 1024 个样本。
- 每帧指标：采集帧内该模块同步入口时间之和，未运行的模块记零；帧间 Promise/通信回调只进入累计和每次指标，不计入每帧指标。
- 任务明细：导出 JSON 的每个模块新增 `tasks`，包含 `taskId/phase/description`、`runs/enabledChecks`、`self/inclusive/frame`、`run/enabled`。`run` 只统计实际运行的同步自身时间，`enabled` 单列启用判断；任务累计及每帧指标包含两者。任务未执行的帧记零，晚出现任务补齐此前零帧；所有样本仍至多 1024。明细复用原计时区间，不新增嵌套计时、不重复计入模块总计。事件和请求仍见原 `categories`，模块总计还包含这些入口，因此不一定等于任务之和。
- 异步完成：从入口开始到原 Promise 完成的经过时间，含等待，不能相加作为 CPU 时间。停止/重新开始或清空后的过期完成回调不写入新数据。
- 未独立归属：await 后续代码、直接 DOM 回调、定时器、Babylon Observable 及 GPU 工作。同步嵌套在已测入口内的未标记代码仍属于该入口；例如 scene.render 内 Observable 归入 Host 渲染。零值不表示模块全部代码没有开销。

这是调度边界的拆分，不改变格步规则的归属：玩家模拟入口同步触发的 Agent 格步决策仍属于玩家模拟任务；Agent 自己注册的模拟与 Debug 任务则归属 Agent。导出保持 version 1，原字段不变，旧报告无法追溯拆分任务；需要刷新 Lab 后清空并重新采集。

生命周期可在运行采集关闭时查看。清空记录也清空生命周期；不会重新执行初始化。销毁时释放采集数据、异步观察的写入资格、UI 和计时器。

自动验证可使用 Host 的 `performance.start/stop/clear/inspect` 接口。Host dispose 完成后，`performance.inspect()` 保留包含释放耗时的最终只读报告；后续开始/清空操作不再生效。

验证：`npm run test:lab-performance`。使用注入时钟测试去重、边界、停止/清空、错误和有界样本，实际面板测试验证采集控制、分类、搜索、DOM 复用和隐藏后停止刷新。
