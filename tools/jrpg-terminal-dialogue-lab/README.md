# JRPG Terminal Dialogue

独立的 70 年代终端风 JRPG 对话界面，根 index.html 提供入口，Vite 多页构建包含此页。

绿磷光与琥珀色显示、CRT 扫描线、字符画城门、姓名牌、逐字对白、分支选择、自动阅读、历史记录、浏览器存档／读档。雾港序章有灯塔和渡船两个结局。

- Enter / Space：显示整句或继续；↑ / ↓ 与数字键选择回应。
- A：自动阅读；L：记录；S：存档；R：读档。
- 自动阅读到分支时暂停，显示设置可调整速度、颜色和扫描线。
- 存档保存于当前浏览器 jrpg-terminal-dialogue:save:v1。损坏存档会显示提示。
- 此页面是独立示例，尚未连接 Dialogue Map 的图数据。无第三方引擎或外部字体／图像依赖。
